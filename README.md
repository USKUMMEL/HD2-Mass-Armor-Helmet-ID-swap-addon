# **Mass ID Swap Blender Addon — Requires HD2SDK-CommunityEdition**

- Allow modders to do a mass armor/helmet ID swap at the same time while storing Units/mesh data only once.
- This addon enables multiple ID swaps at the same time by using schematic JSON data that describes the game armor/helmet slot structure for precise ID replacement.

Tutorial Document: [ID Swap addon Document](https://docs.google.com/document/d/1ya_uxHB3ZFsROxR-lOkNEKN6YmNZ0eIAoel8Lx04aAA/edit?tab=t.0)
